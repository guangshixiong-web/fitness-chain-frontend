# 悦动健身连锁数据中控台 — 产品需求文档（PRD）

## 1. 项目概述

### 1.1 背景
悦动健身连锁在全国多个区域经营健身门店，需要一套数据中控台来统一管理经营数据、服务资料、会员体系和器械运维。

### 1.2 目标
基于 Next.js App Router 构建一套教学级全栈数据管理后台，在原有晴天咖啡中控台功能基础上，增加健身行业特有的会员卡、私教预约和器械巡检三大功能。

## 2. 用户角色与权限

| 角色 | 数据范围 | 可访问功能 |
|------|----------|------------|
| 超级管理员 | 全部 | 所有菜单和按钮 |
| 总部运营 | 全部 | 除用户/角色管理外的所有功能 |
| 区域经理 | 所属区域 | 经营总览、门店查看、服务查看、订单查看、健身业务查看 |
| 门店店长 | 所属门店 | 经营总览、服务查看、订单查看、会员卡办理、私教预约、器械巡检 |
| 数据分析员 | 全部 | 查看分析数据，不含编辑权限 |

## 3. 功能模块

### 3.1 经营分析
- **经营总览**：营业额、订单量、客单价、活跃门店、服务销量、活跃会员；营收/订单趋势图、门店排行、分类占比
- **指标管理**：维护指标定义和启停状态

### 3.2 业务数据
- **区域管理**：区域编码、名称、门店数量、启用/停用
- **门店管理**：门店编号、名称、所属区域、地址、电话、开业日期、启用/停用
- **服务分类**：团课、私教服务、会员卡、SPA理疗等分类维护
- **服务管理**：服务编号、名称、分类、售价、成本、图片、启用/停用
- **订单中心**：订单号、门店、金额、状态、下单时间；支持创建演示订单

### 3.3 健身业务（新增）
- **会员卡管理**
  - 卡类型：次卡、月卡、年卡
  - 状态：生效中、已过期、已冻结
  - 操作：办理（填写会员信息/卡类型/金额/有效期）、编辑、冻结/解冻
- **私教预约**
  - 教练信息：姓名、专长、所属门店
  - 预约流程：待确认 → 已确认 → 已完成（或取消）
  - 时段：09:00-10:00 到 19:00-20:00
- **器械巡检**
  - 器械档案：名称、型号、位置、所属门店、上次巡检时间、状态（正常/关注/维修中）
  - 巡检记录：巡检人、时间、结果（通过/不合格/需维修）、备注
  - 操作：新增器械、编辑、提交巡检

### 3.4 数据接入
- **CSV 数据导入**：下载模板、上传 CSV、预览、确认导入
- **导入记录**：查看历史导入任务和结果

### 3.5 系统管理
- **用户管理**：创建、编辑用户，分配角色和区域/门店
- **角色权限**：角色编码、名称、数据范围、权限配置
- **操作日志**：模块、操作、操作人、IP、结果

## 4. 非功能需求

- 单仓运行：Mock 后端无需额外服务
- 热重载：开发时数据不丢失
- 服务端预取：Dashboard 首屏 SSR
- 权限校验：无权限自动跳转 Dashboard
- 响应式：适配桌面端和移动端侧栏
