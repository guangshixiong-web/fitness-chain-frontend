# 悦动健身连锁数据中控台 — 快速理解路线

## 第一步：从入口理解权限和预取

1. **proxy.ts**：Next.js 中间件门卫，未登录拦截到 /login，已登录拦截 /login 到 /dashboard
2. **app/(authenticated)/layout.tsx**：服务端加载用户信息，无则 redirect('/login')；有则注入 Redux store
3. **app/dashboard/page.tsx**：服务端并行预取 overview + charts，传给 DashboardView 作为 initialData

## 第二步：理解三层数据交互

1. **api.ts**：Axios 实例，客户端所有 API 请求的入口，401 自动跳转登录
2. **api-server.ts**：服务端直接调用 `handleMockApi`，不走 HTTP 请求自身
3. **use-api.ts**：React Hook，管理 loading/error/data/reload，支持 initialData 跳过首次请求

## 第三步：理解 Mock 后端

1. **db.ts**：`createSeedDb()` 生成 5 角色、4 门店、5 服务、36 张会员卡、6 位教练、24 条预约、8 台器械、20 条巡检记录
2. **handlers.ts**：路由分发器，所有 API 走 `handleMockApi(request)` 返回 `{status, body, cookie}`
3. **route.ts**：将 HTTP 请求转换为 MockRequest，调用 `handleMockApiAsync`，应用 Cookie

## 第四步：理解视图层设计

1. **page.tsx**：极薄服务端页面，只做两件事：服务端预取 + 权限边界包裹 + 传入 View
2. **views/*.tsx**：客户端视图组件，负责交互、状态、表单、表格、图表
3. **management.tsx**：config-driven 通用 CRUD 视图，通过 `kind` 参数复用于区域/门店/分类/服务

## 第五步：理解新增三大功能

| 功能 | 实体 | 端点 | 视图 |
|------|------|------|------|
| 会员卡 | MemberCard | /member-cards | member-cards.tsx |
| 私教预约 | TrainerBooking | /trainer-bookings | trainer-bookings.tsx |
| 器械巡检 | Equipment + Inspection | /equipment + /equipment-inspections | equipment-inspections.tsx |

每个新增功能都遵循同样的模式：db.ts 种子数据 → handlers.ts API → view.tsx 表格+表单+状态操作。

## 推荐阅读顺序

```
proxy.ts
  → app/(authenticated)/layout.tsx
    → app/dashboard/page.tsx
      → src/views/dashboard.tsx
    → src/lib/api-server.ts
    → src/lib/api.ts
    → src/hooks/use-api.ts
      → src/mock/handlers.ts
        → src/mock/db.ts
```
