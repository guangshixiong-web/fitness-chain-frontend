## 2. 核心架构

### 2.1 门卫（proxy.ts）
- 检查 `yuedong_session` Cookie
- 未登录访问受保护页面 → `/login`
- 已登录访问 `/login` → `/dashboard`

### 2.2 服务端布局（app/(authenticated)/layout.tsx）
```
async Server Layout
  → loadAuthenticatedUser() 读取 Cookie 解析用户信息
    → 无用户信息 → redirect('/login')
    → 有用户信息 → Provider(user) + AppShell
```

### 2.3 三层数据交互
| 层 | 文件 | 职责 |
|--|--|--|
| 客户端请求 | `src/lib/api.ts` | Axios 实例，baseURL `/api/v1`，拦截 401 跳转登录 |
| 服务端请求 | `src/lib/api-server.ts` | `serverApiFetch` 直接调用 Mock handlers，避免自调用 HTTP |
| 通用 Hook | `src/hooks/use-api.ts` | `useApi(url, initialData)` 管理 loading/error/data/reload |

### 2.4 Mock 后端（src/mock/）
- **db.ts**：内存数据库，进程内共享（`globalThis.__yuedongFrontendMockDb`），热重载不丢失
- **handlers.ts**：完整 REST 路由分发，认证/业务/系统/新增健身业务全部支持

## 3. 状态管理

### 3.1 Redux auth slice
```
{ user: AuthUser | null, loading: boolean }
actions: clearAuth
thunks: loadMe（调用 /auth/me）
```

### 3.2 服务端预加载
- `makeStore(user)` 创建 store 时注入 preloadedState
- 客户端 `Provider` 复用同一 store，避免 hydration mismatch

## 4. 新增功能技术实现

### 4.1 会员卡管理
- Mock 实体：`MemberCard`（cardNo, memberName, memberPhone, cardType, totalVisits, remainingVisits, price, startDate, endDate, status）
- 端点：`/member-cards` GET/POST/PATCH + `/member-cards/:id/status` PATCH
- 视图：`src/views/member-cards.tsx`，支持办理、编辑、冻结/解冻

### 4.2 私教预约
- Mock 实体：`Trainer` + `TrainerBooking`（bookingNo, memberName, trainerId, sessionDate, timeSlot, status）
- 端点：`/trainers` GET + `/trainer-bookings` GET/POST/PATCH
- 视图：`src/views/trainer-bookings.tsx`，支持状态流转按钮

### 4.3 器械巡检
- Mock 实体：`Equipment` + `EquipmentInspection`
- 端点：`/equipment` GET/POST/PATCH + `/equipment-inspections` GET/POST
- 视图：`src/views/equipment-inspections.tsx`，Tabs 切换「器械档案」和「巡检记录」

## 5. UI 设计

- 主色调：emerald（健身绿色）替代 amber（咖啡暖色）
- 组件库：`src/components/ui.tsx` 集中封装 Button/Input/Dialog/Table/Toast 等
- Tooltip：`delayDuration={250}`，必须由 Tooltip.Provider 包裹
- HoverCard：与 Tooltip 分工，Tooltip 用于纯文字短提示
