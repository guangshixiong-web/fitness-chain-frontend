# 悦动健身连锁数据中控台 — 运行说明

## 环境要求

- Node.js 20+
- npm 10+

## 安装与启动

```bash
# 进入项目目录
cd 悦动健身连锁中控台-仅前端框架

# 安装依赖
npm install

# 开发模式（端口 5173）
npm run dev

# 生产构建
npm run build

# 启动生产服务
npm run start
```

## 访问地址

- 登录页：http://localhost:5173/login
- 经营总览：http://localhost:5173/dashboard

## 注意事项

- Mock 数据保存在 Node.js 进程内存中，刷新页面不会丢失，重启 dev server 会重置
- 密码修改后也会保存在内存中，重启后恢复默认值
- 图片使用 Unsplash，需保持联网以显示服务图片
